# Rock Solid Fencing — Leads Dashboard

Next.js lead management dashboard (Leads + Analytics). Backend API runs on Google Cloud Functions.

See the parent [`../README.md`](../README.md) for full setup (GCP, intake endpoint, Vercel).

## Local development

```bash
cd frontend
cp .env.local.example .env.local
npm install
npm run dev
```

Open [http://localhost:3002](http://localhost:3002) and sign in with `DASHBOARD_API_KEY`.
